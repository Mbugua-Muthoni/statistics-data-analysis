# Statistics Data Analysis

This repository contains beginner-level statistical data analysis projects using R.

## Project 1: Iris Data Analysis

For this project, I used the built-in Iris dataset in R to practise basic statistical analysis.

### What I did

* Explored the structure of the dataset
* Viewed summary statistics
* Calculated means
* Calculated standard deviations
* Examined the frequency of each species
* Created a scatter plot using R

### Tools Used

* R
* RStudio
* Basic statistical methods
* Data visualization

### Purpose

The purpose of this project was to practise using R for statistical data analysis and to develop my understanding of how data can be explored, summarized, and visualized.

### What I Learned

Through this project, I practised working with a dataset in R, calculating descriptive statistics, and creating a simple visualization to explore relationships between variables.
